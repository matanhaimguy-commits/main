# carousel-machine, organic adapter

Pass the full Post Card and this file with every carousel-machine call. Source: ORGANIC-OS.md 7.3 and 7.4.

- Job, belief, pillar, CTA and keyword come from the Post Card, not from a free brief.
- **Slide 2 works alone as a hook** (second-chance distribution).
- 7 to 12 slides; 4:5 at 1080x1350 (the publishing API refuses 3:4); GPT Image 2.5 at aspect 4:5, 2k, medium.
- StraightScale preset: accent **#B31217** (highlight boxes), logo red #BE0F18, gold counter #DD9A10; register per the
  brain's voice card ("ti" until D2).
- Formats from the library: framework / "steal my system" (B4), self-audit checklist (B3, pairs with the lead magnet),
  mistakes list (B1), teardown (B2/B3), comparison (B5), opinion / values (B7, from the contrarian vault only).
- One ask, on the last slide and in the caption, matching the card's `cta_type`.
- Caption: first line restates the hook with the search words; 3 to 5 specific hashtags; CTA repeated with the keyword.
