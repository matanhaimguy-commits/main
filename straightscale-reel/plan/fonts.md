# Fonts
Brand fonts given by the client, so no font research needed.
| Role | Font | Weights used | Source | Licence |
|---|---|---|---|---|
| Headlines, promise card, CTA word | Playfair Display | 700, 900, italic 700 | @fontsource/playfair-display (npm, Google Fonts files) | SIL OFL 1.1 (commercial OK) |
| Captions, labels, UI | Montserrat | 500–900 | @fontsource/montserrat | SIL OFL 1.1 (commercial OK) |
Note: Playfair uses old-style numerals, so digits on cards are set in Montserrat 800 for legibility.
Albanian glyphs ë ç Ë Ç are covered by the latin subset (checked in render).
