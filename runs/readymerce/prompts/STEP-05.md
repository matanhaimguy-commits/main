## 3 · DEFINITIONS (only the ones this step uses)

* **URL record** `URL-##` — one openable page expected to yield records: a thread with its comments, a star-lane review page, a video's or post's comments, a Quora question, a forum thread, an ad's comments, an operator-pasted file.
* **Lane** — the harvest route a URL takes: `reddit_post+comments · reddit_comments_only · amazon_critical · amazon_5star · amazon_3star · trustpilot_balanced · tiktok_comments · youtube_comments · youtube_transcript · fb_post_comments · quora_answers · forum_thread · ad_comments · owned_paste`.
* **Recipe card** `RC-##` — a pinned, paste-ready actor input with every count field set, its price, output field map and fallback chain; 06 runs the card, never an improvised call.
* **est_records** — `min(engagement, lane cap) × lane yield`; lane cap = the recipe's count field; default yields: Reddit comments 0.35 · Amazon critical 0.6 · 5★ 0.4 · 3★ 0.7 · Trustpilot 0.5 · TikTok comments 0.25 · YouTube comments 0.3 · FB comments 0.3 · Quora answers 0.6 · forum thread 0.4. The ~10% usable rate applies to search hits, not to opened threads.
* **Status vocabulary** — `LISTED` (page or dataset row seen: title + engagement read) · `FETCHED` · `SCRAPED` · `QUERY-ONLY` (memory or an unopened snippet; counts toward no floor) · `BLOCKED` (source access only) · `OPERATOR-PASTE`.
* **Harvester** `HV-##` **/** `HV-CP-##` — the agent that owns one PB (or one thin CP): its URL list, floors, recipe cards, partial file.
* **PLAN-VALIDATED / PLAN-THIN** — a PB or CP whose Σ `est_records` reaches 1.5× its record floor / does not (a label; the harvest runs either way).

## 6 · VALIDATION — what earns each label

1. **Rank keys.** Reddit, forum and Facebook threads: comment count → upvotes → recency; reviews: helpful votes within the star lane, most recent first; TikTok and YouTube: `commentCount` then views. Recency floor: ≥30% of Reddit URLs from `new` / last-90-days sorts. Rows meeting all → **LISTED**.
2. **Listing.** A URL is LISTED only after its page or dataset row was seen (title + engagement read). From memory or an unopened snippet → **QUERY-ONLY**, counts toward no floor, used only after direct fetch AND Apify both returned nothing.
3. **Independence.** OP authors differ → independent threads; crossposts and duplicates collapse with `duplicate_of`.
4. **Population attribution.** `population_tags[]` filled only when the population marker is in the title, OP or visible comments (cite the phrase); otherwise the URL counts for the PB only.
5. **Plan test.** Σ `est_records` per PB ≥ 1.5 × 40 and per CP ≥ 1.5 × 25 → **PLAN-VALIDATED**; below → **PLAN-THIN** with the lanes to extend; URLs are added in this step and the harvest runs either way.
6. **Concentration cap.** One URL carries at most 25% of a PB's Σ `est_records` — one thread is never half the corpus.
