## 3 · DEFINITIONS (only the ones this step uses — verbatim where the source matters)

1. **Value equation.** Value = (Dream Outcome × Perceived Likelihood of Achievement) ÷ (Time Delay × Effort & Sacrifice). The top two create value, the bottom two destroy it.
2. **Benchmark band.** ≥3 above-floor networks with an offer context make a band; fewer print `BAND: NULL`. An element is copied only when ≥2 independent networks converge on it.
3. **Ladder shapes.** **A · Buy X Get Y FREE** (`1+1 → 2+2 → 3+3`; free units beat the equivalent %), **B · supply-duration** (`1 / 3 / 6-month`), **C · kit / system** (Single → Kit → Full System, refill where one exists). Struck anchors are singles-math ("worth $X bought singly"), never an invented "was" price; the **decoy** makes the target tier obviously win.
4. **Subscription guardrails.** Pre-select only when replenishment is behaviourally real (PT-## cadence + repurchase language), the one-time option stays visible, cancel is frictionless and the gift stacks; otherwise `NOT PRESELECTED` — a forced default cannibalises the high-AOV tiers.
5. **Guarantee types.** `unconditional`, `conditional` (after a stated use), `performance` (a stated result or the refund), `anti` (no refunds as confidence; low-ticket demonstrable consumables). The guarantee closes residual fear, never opens.
6. **Real constraint.** Scarcity names what is literally limited; urgency names an announced price rise or a gift deadline; a resetting timer is not a constraint; `NONE — evergreen` is an honest value. **Rationale for generosity** = one sentence on why the deal exists.
7. **Named offer / offer beat.** `[Result] + [Timeframe] + [Container]` in the avatar's words; the offer beat is ≤40 words carrying tier, gift, guarantee and urgency source — the story's last beat and P.S.
8. **The seven attach lenses.** Usage journey (before/during/after), adjacent pain, completion (a full M-2 protocol), consumable attach, premium upgrade, multi-pack/household/gift, cross-tribe identity.
9. **Profit per session.** `CVR × AOV × margin` per tier; decides between LIVE offer variants once a winner adset exists — never the AOV ratio, because a higher AOV lowers CVR.
10. **Four forces / two futures.** Push, pull, anxiety, habit; a switch happens only when push + pull > anxiety + habit. LACK future = an IB-## Q-##; FULFILLMENT future = an H-## scripted from documented lack details; a credentialed voice inside it carries the `AUTHORITY` tag.
11. **Angle (AN-##).** A strategic reframe: premise, **strategic frame** (story/transformation, mechanism reveal, bold proclamation, social proof/us-vs-them, fear+hope), lane, **territory** (CONTROL = the incumbents' argument, CHALLENGER-n = run against it by n incumbents, FRESH = unclaimed), belief to break, structure ST-##, awareness entry + avoid-list. The six angle questions: what he believes now, the reframe, the core tension, who feels it most, what he tried and what its failure meant, what he fears for his identity if this fails too. Every ranking prints "the research favorite, not the final winner."
12. **Hook classes (five).** Scene in progress, direct avatar callout, blunt personal admission, grounded belief correction, unexpected concrete contrast. **Discovery frames:** A independent research, B trusted peer, C accidental encounter.
13. **Similarity.** Shared attributes over five (frame, pain, structure, image scene, lead hook class); ≥2 of 5 shared = ≥40% similar → one cell re-aimed.
14. **Adset = avatar.** Delivery groups by persona; an avatar-adset is a desire test with a person attached; a desire-adset with no person is a demographic. The tested variable across adsets is WHO. **Exception:** a stage 1–2 market or a NARROW portfolio → one adset, ads = angles, tested variable = WHICH ARGUMENT.
15. **Playbook labels.** Every line carries `VERBATIM VOC`, `OBSERVED PATTERN`, `ANALYST INFERENCE` or `HYPOTHESIS`; every ideated concept `SYNTHESIZED CREATIVE IDEA`. **The ten opening styles:** raw emotion, timeline, question, confession, physical evidence, contradiction, frustration, update, reassurance seeking, "I tried everything."

## 6 · VALIDATION — what earns each label

1. **Offer strength.** STRONG = screenshot PASS + strength floor PASS + validity PASS + margin survives every tier + a real urgency source or an honest `NONE — evergreen`; ACCEPTABLE = one miss; WEAK = two or more (rebuild once on shape A, then ship labelled).
2. **Bottom-of-equation test.** ≥1 time-delay lever and ≥1 effort lever with IDs; outcome-only stacking → FAIL, printed; the offer still ships.
3. **Bonuses before discounts.** The headline is free units, a gift or a guarantee; flat money-off <25% as the headline → rebuild once, then ship labelled.
4. **Subscription guardrails** per §3.4; otherwise `NOT PRESELECTED`.
5. **Real-constraint test.** Every urgency line names the literal constraint; a resetting timer → `NONE — evergreen`.
6. **Gift test.** Per §4.5: no OBJ-## or outcome → `UNTIED — padding`, listed last.
7. **Economics labels.** Each band prints PASS / BORDER / BELOW with its number; BELOW prints the fix order as a recommendation. Labels describe; the test runs either way.
8. **Trigger evidence.** Every force and activation event carries a Q-##; `cost_of_inaction` only from wallet quotes, else `UNQUANTIFIED`; the fulfillment future per §3.10.
9. **Cell readiness.** READY when every field carries an ID, `tested_variable` is exactly one, `held_constant[]` lists the six constants, `voc_roots ≥4`, proof ≥1 at EXISTS / SHOOTABLE-NOW, B-## named; otherwise FLAGGED (missing field named); FLAGGED cells ship and launch last.
10. **Grid diversity (the ad prompt re-checks it).** Per avatar ≥3 strategic frames and ≥2 awareness levels; no two ads of one avatar share frame + pain or frame + mechanism; no premise family >1/3; 8–12 structurally distinct concepts; similarity <40%. Collisions swap from the reserve queue; <8 distinct concepts prints `GRID: THIN (n)`.
11. **Adset = persona tag.** Every creative is pre-mapped to one avatar; one that reads true for two adsets is re-aimed.
12. **Capacity.** N_adsets ≤ `max_adsets` and ≤5; 3–5 ads per adset; a short budget trims adsets in `testing_sequence` order, never below one.
13. **Kill-rule data minimum.** No CPA-based kill before 2× `breakeven_cpa` spent per adset (or 5–10 conversions); no forced spend.
14. **Playbook QC (13 checks, each PASS/FIXED).** No synthesized line presented as verbatim, no single-poster overcount (authors, not comments), outcomes ≠ desires, problem states ≠ angles, "I tried everything" ≠ an angle, every angle answers the six questions, contradicting evidence kept, every conclusion traces to IDs, openings sound like the platform, synthesized concepts labelled, usable by a human, usable by an LLM, concise.
15. **Contract completeness.** Per §4.27; STRANGER TEST printed with its six artefacts.
16. **Handoff schema lint.** Per §4.28; `handoff_version` 2, or 1 with the `LATE-BOUND: 13.*` list.
