# OPERATING RULES (identical in every step — read once)

1. **Goal first.** Section 4 lists the objects this step must find. Everything you read, fetch or scrape serves one of them. Do not do broad research.
2. **Real evidence only.** Every quote is verbatim with a URL, platform, date and (if visible) handle; never paraphrase into a quote, never merge two comments, never invent a username, date, URL, ad metric, revenue figure, study or percentage. Counts print with their denominator (e.g. `14 of 61 authors`). Sample-based figures print `SAMPLE(N)`; unsized things print `UNSIZED — method: …`; unknowns print `UNKNOWN`, never a plausible guess.
3. **Labels, never gates. Every object is always produced.** Findings earn VALIDATED · SUPPORTED · EARLY SIGNAL · HYPOTHESIS by the rules in section 6; REJECTED exists only for category errors (a demographic is not an avatar, a hook is not an angle). Thin evidence changes the label, never whether the object is written. A missed floor triggers the next source in the fallback chain inside the time box, then prints `PARTIAL — <what is missing>` and the work continues. The only stop in the whole workflow is a blank product name.
4. **Infer what is not given.** Ingredients, specs, price, category, competitor names — blank means infer from our PDP, competitor PDPs, supplier listings, category norms and the corpus, print `INFERRED: <source>` or `ASSUMED`, and continue. Never ask for a missing input; never wait for one.
5. **Independence is counted by advertiser network, not page.** Ten page identities of one operator are one competitor. One winning ad is a signal, not validation. Longevity proves spend commitment; replication across independent networks proves the market rewards the argument.
6. **Read only your INPUTS — the HANDOFF JSON first.** Open `nn-HANDOFF.json` of each input step, then the full file only at the sections it points to; never re-derive upstream outputs from memory, never import anything from other products, brands or earlier projects. A field that is not there yet prints `LATE-BOUND: <file.field>` and the object ships without it.
7. **Tool-portable.** Each operation is named generically, then mapped to GetHookd / Meta Ad Library / Apify / TranscriptAPI / browser. If a tool is absent, use the next mapping; if none exists, print `NOT RUN — no tool` and continue everything that does not depend on it. Never call a substitute an equivalent.
8. **Batch the waits.** Launch every actor, transcription or fetch of a unit in one go, then poll; never launch → wait → launch.
9. **Runtime-portable, scope-aware.** Run this step alone in a fresh session or as a delegated agent; with `SCOPE: <id>` do everything for that id only and write `nn-partials/<file>.<id>`. Write output exactly as section 7 names it, under `<run>/[brand-slug]/foundation/`, and end by writing `nn-HANDOFF.json` (≤2 KB: the handoff fields as values or `{file, section}` pointers).
10. **Print counters as you go** (records, sources, floors) so under-collection is visible, not discovered at the end.
11. **Ask nothing mid-run.** Make the routine calls yourself; state assumptions inline as `ASSUMED: …`.
12. **Write safely.** Write your output as `<file>.partial` from the first line, append as you go, rename to `<file>` after the COVERAGE STATEMENT; keep `nn-PROGRESS.md` with `RESUME POINT: …`; write only your own files, never a temp or scratch path.
13. **Stay bounded.** Respect the `max_minutes` / `max_tool_calls` in your brief; a blocked source gets at most 3 attempts across its chain; when the box ends, synthesise what exists, write PARTIAL with the resume point, and end.
14. **Close with the COVERAGE STATEMENT.** No file is complete without it.

Beyond the rules: direct evidence stays apart from interpretation (`[D]`) and assumption (`[A]`) · an ad is never a winner because it exists — longevity, replication and independent recurrence decide, with the INCUMBENT downgrade · a claim in an ad is `COMPETITOR-CLAIMED`, never a product fact · a study or expert enters only when fetched and filed · evidence vocabulary (levels, links, `basis: cited | competitor-claimed | category-typical | inferred`) is a column, never a filter.

# THE LABEL VOCABULARY

Four quality labels — `VALIDATED · SUPPORTED · EARLY SIGNAL · HYPOTHESIS` — computed in code from counted evidence per the step's rules; `REJECTED` only for category errors (a demographic is not an avatar, a hook is not an angle, a problem the product cannot touch), never for thin evidence, a missing ingredient, source, size or budget. Qualifiers ride on a label (`VALIDATED-2NW`, `ANECDOTE` …); verdict words (`DOMINANT`, `OWNED`, `LOCKED` …) print beside their evidence and are not labels.
**The tags:** `INFERRED` · `ASSUMED` · `LATE-BOUND` · `SYNTHESIZED` · `AUTHORITY` · `OPERATOR-VALIDATES` · `PARTIAL` · `UNSIZED` — things the team reads later; none of them waits for anyone.
**Object states:** `UNPROVEN` (written in full, ranked last) · `RESERVE` · `BLOCKED-ON-TOOL` (a tool or source access state only, never an object verdict).
**Honesty tokens:** `NULL — searched:` · `SAMPLE(N)` · `NOT MAPPED` · `UNSCANNED` · `PARTIAL (N=n/floor) — chain exhausted:` · `COMPETITOR-CLAIMED` · `OPERATOR-PASTE` · `HAND-COUNTED` · the tiers `[R-PAGE] [R-SCRAPE] [R-TOOL] [R-WALLED] [R-SNIPPET] [R-PUB] [R-OWNED]` replace every value that would otherwise be invented. Labels and tags describe; nothing sequences on them.

# RESEARCH ISOLATION
Nothing enters a file unless the operator supplied it as an input to this run or it exists in the source material designated for this run. Language recalled from model memory is not VOC; a model-recalled community, study, competitor or molecule enters only as `HYPOTHESIS` until fetched and filed. Step isolation: 02 records and 03 interprets · 04–06 search the problem, never the product · 07 reads awareness and sophistication as two objects · 08's two stamps (corpus, advertisers) never seed each other · 09 reads before it judges · 10 cites only its literature ledger, ranks by persuasion first · 11 never inherits a belief from ad copy · 12 runs no new research · 13 traces every choice to what the market already trusts.
