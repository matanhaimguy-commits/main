## Signature device
An instrument wall with a ball as the player. Every object on the set is a sound source with a visible
response: it lights up, flips or wobbles on impact while the matching note plays, so the ear and eye agree
on every hit. The set changes family every 5-10 s (ducks, glass tiles, horns, chimes, crystal discs, cubes,
keys), which keeps novelty high without breaking the single ball path. The camera is a smooth follow-cam that
keeps the ball near the centre third, slightly above, panning and dropping with it. Wall lettering ("like &
follow", "subscribe", the handle) is built into the set as props, so the calls to action never cover the
action.

## Build it in our studio
- Engine: `canvas` with fake-3D projection for a stylised version (flat-shaded primitives on a wall plane,
  ball as a shaded sphere, camera as a 2D follow transform with depth scaling). Photoreal glass and chrome
  would need `blender` (not in our stack).
- Scene plan: 1) beat map the licensed or composed track; 2) solve the ball path so each landing falls on a
  beat (parabolic arcs between targets placed after the fact); 3) assign a target family per musical
  section; 4) target reactions (light, flip, wobble) via `spring()`; 5) follow camera with a lag spring;
  6) close the loop by placing the last target at the first frame's position.
- Hard part: placing targets to fit the beats while keeping arcs natural. Solve backwards from beat times:
  pick arc durations from beat gaps, compute landing positions, then place the targets there.
- Difficulty 4 for the polished 3D look; a flat 2D version is a 2-3.
