# Awesome DESIGN.md (VoltAgent)

Source: https://github.com/VoltAgent/awesome-design-md (MIT).

Each folder in `design-md/` holds a `DESIGN.md` (colors, typography, spacing, components, layout patterns) for one brand.

## How to use
1. Pick the brand closest to the requested look.
2. Read `design-md/<brand>/DESIGN.md` in full.
3. Build the UI following its tokens and patterns; adapt to the user's own content and brand — don't copy logos or trademarks.
